tiny-ai-chat

An AI chat widget for any website in under 10 KB. Your API key stays on your server; answers stream from OpenAI, Gemini or Claude.

GitHub Quick start Built with lithent

Try it: the chat button is in the bottom-right corner.

This demo runs without an AI or a server: a small script answers from prepared replies using the same protocol as a real relay, so what you see is the real widget.

One script, one tag

<script src="https://cdn.jsdelivr.net/npm/tiny-ai-chat/dist/tiny-ai-chat.js"></script>
<tiny-ai-chat endpoint="https://your-relay.example.com/api/chat"></tiny-ai-chat>
  • Shadow DOM: your page's CSS and the widget leave each other alone.
  • Streaming, stop, retry, safe Markdown, keyboard and screen readers.
  • Full screen on phones; the conversation stays across page loads in the tab.
